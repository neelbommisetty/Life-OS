# Life-OS

A personal software environment for understanding life and acting with context. The current implementation is a local tools API, HTTP CLI, and web task/calendar workspaces.

Start with the [documentation map](docs/README.md) and [current state, approvals, and active work](docs/STATUS.md). Read the [vision](docs/vision/VISION.md) for the ambition and [AGENTS.md](AGENTS.md) before development.

Run commands and implementation detail: [tools](packages/tools/README.md), [API](packages/tools/API.md), [web](apps/web/README.md).
