# Feature specifications

These documents define behavior. Approval and delivery live in the [scope register](../STATUS.md#scope-register); a confirmed product decision does not approve every feature in a specification.

| Specification | Scope |
| --- | --- |
| [Hands](HANDS.md) | Todo and calendar decisions, including implemented behavior and explicitly later integrations. |
| [Leisure](LEISURE.md) | Library and diary decisions; only the first cut in the tools brief is approved and implemented. |
| [Shared API](API.md) | Implemented September 17 transport milestone. |

The [tools implementation brief](../../packages/tools/README.md), [API contract](../../packages/tools/API.md), and [web guide](../../apps/web/README.md) hold code-adjacent detail. Proposed shared-record and adaptive-view contracts belong in [architecture](../architecture/DATA-AND-VIEWS.md).
