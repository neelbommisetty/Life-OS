# Vision and ambition

[Current Vision](VISION.md), adopted September 5, 2026, describes the connected personal environment Life-OS aims to become. [Product principles](../../PRODUCT.md) describe its user, purpose and experience. Neither is an authorization to implement every proposed feature.

Start at the [documentation index](../README.md) for the full map, or [STATUS.md](../STATUS.md) for actual capabilities, approved scope and active work.

Technical boundaries live in [architecture](../architecture/ARCHITECTURE.md); behavior contracts live in [specs](../specs/README.md); concrete delivery plans live in [plans](../plans/README.md). The former [identity proposal](IDENTITY-CONNECTIONS-AND-SECRETS.md) points to the canonical architecture.

The [August 28 legacy planning set](legacy/2026-08-28/README.md) is historical reference only. Its PRD, architecture and technology choices do not govern current work. Do not use it as the default reading path.
